# 行测练习 Web App

## 打开方式
直接双击 `index.html`，或用任意浏览器（Chrome / Edge / Safari / 手机浏览器）打开即可。单文件、无需联网、无需安装。

## 功能
- **题库**：按模块筛选、关键词搜索；新增 / 编辑 / 删除题目；导入导出 JSON、CSV。
- **练习**：选模块、题量、随机或顺序；逐题即时反馈（正确答案 + 解析）；可选计时；结束后按模块统计正确率。
- **错题本**：答错自动记录（错误次数、最近错误时间）；可只重做错题；手动“已掌握”移出，或连续答对 2 次自动移出；可清空。
- **统计**：累计作答数、总正确率、各模块正确率。
- **默认题库**：内置从私有仓库 `Quasimodo66/xingce-prep` 导入的 2552 题（真题 2531 + 模拟题 21），可按类型（真题/模拟题/示例题/自定义）筛选和练习。
- 另有 10 道 **示例题**（自编示意题，非真题），可在“帮助”页切换；“恢复默认题库”可切回导入题库。

## 题库来源与重新导入
- 真题：仓库 `真题/ocr/tiku.json`（国考 2015–2026、江苏省考 2021–2025，答案为机构整理/网友回忆版，**非官方**）。来源字段写明年份、卷别、题号；同一题出现在多卷时只保留一份，其余卷写在来源里。
- 模拟题：仓库 `练习/政治常识押题_练习.md`（15 题）和 `练习/逻辑填空与类比_分级练习.md` 中标“自编”的 6 题，来源写“模拟题｜套名第N题”。`模考/` 目录只有笔记，没有题目。
- 未导入：依赖图片的题（图形推理、图片选项、图表型资料分析材料）、无答案的题、选项 OCR 乱码的题。详见 `import_report.json`。
- 标 ⚠“需核对”的题：仓库标记为 OCR 识别或答案存疑，请以原卷为准。
- 重新导入：把仓库的 `真题/ocr/tiku.json` 和 `练习/` 下四个 md 文件（改名为 zz_q.md / zz_a.md / lt_q.md / lt_a.md）放到一个目录，运行 `python3 import_from_repo.py <目录>`，会重新生成 `questions.json`、`import_report.json`，并把题库嵌入 `index.html`。

## 题目字段
| 字段 | 说明 |
|---|---|
| id | 唯一编号（真题为 `卷代码-题号`，如 `ds2025-5`） |
| module | 常识判断 / 言语理解与表达 / 数量关系 / 判断推理 / 资料分析 |
| stem, options{A..D}, answer, explanation | 题干、选项、答案（A-D）、解析 |
| source | 来源文字（含同题出现的其他卷） |
| type | 真题 / 模拟题 / 示例题 / 自定义 |
| year | 整数年份；未知为 null（模拟题、示例题为 null） |
| exam | 国考副省级 / 国考地市级 / 国考行政执法 / 江苏省考B类 / 江苏省考C类 / 模拟题 / 示例题（国考 2021 年“市地级”归入国考地市级，2019–2020 年“省级”归入国考副省级） |
| difficulty | 难度 1–5，暂为 null，可在编辑表单中填写 |
| qtype | 一级题型（模块下）（如 逻辑填空、片段阅读、语句排序、类比推理、定义判断、逻辑判断、数学运算、数字推理、政治常识、法律常识……），识别不了为 null |
| qsubtype | 二级子类（可空） |
| qtype_src | 分类来源：repo / explanation / rule / manual |
| material_id | 资料分析共用材料编号，材料正文在 materials 表 |
| appearances | 同一道题出现在多卷时的列表 `[{exam,year,n,paper}]`，第一项为主卷（exam/year 取它） |
| note | 备注（需核对、推导答案等） |

## JSON 格式
```json
{"version":2,
 "materials":{"ds2025-m1":"材料正文……"},
 "questions":[{"id":"q1","module":"资料分析","stem":"题干","options":{"A":"..","B":"..","C":"..","D":".."},
   "answer":"B","explanation":"解析","source":"来源","type":"真题","year":2025,"exam":"国考地市级",
   "difficulty":null,"qtype":"增长类","material_id":"ds2025-m1"}]}
```
旧格式（直接是题目数组）仍然可以导入，缺少的新字段为 null。

## CSV 格式
UTF-8，首行为表头。题目 CSV：
```
id,module,stem,A,B,C,D,answer,explanation,source,year,exam,difficulty,material_id,qtype,type
```
材料单独一个 CSV（题库页“导出材料 CSV”），表头 `material_id,text`，导入时 App 按表头自动识别。year、exam、difficulty、material_id、qtype、type 可留空；旧的 10 列 CSV 仍可导入。字段含逗号、双引号或换行时用英文双引号包裹，内部双引号写成 `""`。

## 统计
练习时记录每题用时。统计页按模块和题型显示正确率与平均用时；“导出统计 JSON/CSV”导出按模块、按题型的统计和错题列表（id、模块、题型、考试、年份、错误次数、最近错误时间）。


## 两级题型（module → qtype → qsubtype）
- 常识判断：政治 / 经济 / 法律 / 历史 / 地理 / 科技 / 人文 / 生活常识/其他
- 言语理解与表达：逻辑填空；片段阅读（中心理解、细节判断、标题填入、语句排序、语句填空、下文推断）；语句表达
- 数量关系：数学运算（行程、工程、经济利润、排列组合与概率、几何、容斥、年龄/和差倍比、最值/抽屉、其他）；数字推理
- 判断推理：图形推理；定义判断；类比推理；逻辑判断（翻译推理、真假推理、分析推理、加强削弱、原因解释、归纳推理）
- 资料分析：增长类 / 比重类 / 平均数类 / 倍数类 / 综合分析 / 其他计算
分类优先级：仓库 subtype → 解析中「本题考查…」→ 题干作答指令规则；无法确定则留空（qtype=null）。字段 `qtype_src` 记录来源。图形推理多数因图片未入库，但题型可选。重新分类：`python3 classify_qtypes.py`。

## 添加到手机主屏幕
本文件可双击用浏览器打开。页面已设置标题/图标为「行测刷题」（apple-touch-icon、web manifest data URI）。**注意**：用 `file://` 本地打开时，iPhone Safari / Android Chrome 的「添加到主屏幕」对图标与独立显示支持很有限或不可用；若要稳定显示名称和图标，需要把 `index.html` 放到 https 网站（例如 GitHub Pages），本仓库不会代为创建或推送 Pages。

## 配图题目
图形推理、图表资料、公式乱码题等以 `img/*.jpg` 原卷截图展示（相对路径，需与 `index.html` 一同托管）。练习页选项为 A/B/C/D 按钮。

## 数据存储
内置默认题库写在 index.html 里；你对题库的修改（增删改）、错题本、统计数据保存在**当前浏览器的 localStorage** 中。清除浏览器数据、使用无痕模式或换浏览器/设备都会看不到原数据，**请定期在“题库”页导出 JSON 备份**。
